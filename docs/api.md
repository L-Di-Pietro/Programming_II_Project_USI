# QuantBacktest HTTP API Reference

This document is the comprehensive HTTP reference for the QuantBacktest backend (FastAPI, mounted at `http://127.0.0.1:8000` by default). It is hand-written to satisfy the *USI Programming in Finance II* rubric's "API documentation" requirement; the **live OpenAPI specification** is always available at <http://127.0.0.1:8000/openapi.json> and the Swagger UI at <http://127.0.0.1:8000/docs>, both auto-generated by FastAPI from the Pydantic schemas in [`backend/api/schemas.py`](../backend/api/schemas.py). When the live spec and this document disagree, the live spec is authoritative.

## 1. Conventions

### Base URL

| Environment | Base URL |
|---|---|
| Local dev (default) | `http://127.0.0.1:8000` |
| Docker compose | `http://localhost:8000` (via reverse-proxy) |
| Production | configurable via `API_HOST` + `API_PORT` in `.env` |

The frontend dev server (Vite, port 5173) proxies `/api/*` to the backend per [`frontend/vite.config.ts`](../frontend/vite.config.ts).

### Authentication

**None in v1.** The application is designed as a single-user local tool — every backtest a user submits is their own. Adding auth would require a session/user table and a redesign of every `BacktestRun` row to carry an `owner_id`. Out of scope until v2.

### Content-Type

Every request and response uses `application/json` unless explicitly noted otherwise.

### Versioning

Versioning follows the live OpenAPI spec at `/openapi.json` (`version: "0.1.0"` at submission, declared in [`backend/main.py:110`](../backend/main.py)). Breaking changes will bump the spec version. There is no `/v1/` URL prefix in v1 — the path-prefixed convention will be introduced when the first breaking change ships.

### Pagination

No pagination in v1. The only list endpoint that could grow large is `GET /backtests`, which accepts a `limit` query parameter (default `50`). Other list endpoints (`/assets`, `/strategies`) return all rows; the universe is bounded (~36 assets, 11 strategies) and the payloads are < 50 KB.

### Error envelope

Every error response follows the FastAPI convention:

```json
{ "detail": "Human-readable error message" }
```

FastAPI's validation errors carry a richer structure:

```json
{ "detail": [{ "loc": ["body", "asset_symbol"], "msg": "field required", "type": "value_error.missing" }] }
```

See [§8 Error catalogue](#8-error-catalogue) for the full list of status codes the app raises.

### Timestamps

All timestamps in requests and responses are **ISO-8601 strings interpreted as tz-naive UTC**. The database stores them as tz-naive `DATETIME`. Do not send timezone-suffixed strings (`...Z`, `+00:00`) — Pydantic will accept them but the stored value will silently differ from what you sent.

### Numeric types

All currency and price values are `float64`. There is no fixed-point money type in v1.

## 2. Health

### `GET /healthz`

Defined in [`backend/main.py:126`](../backend/main.py).

**Purpose.** Service liveness + the current LLM configuration. Used by the frontend on app load to decide whether to render the AI-report UI.

**Request.** No body, no query parameters.

**Response — `200 OK`** (`HealthResponse`):

| Field | Type | Description |
|---|---|---|
| `status` | `str` | Always `"ok"` when the service is up. |
| `llm_enabled` | `bool` | Whether the LLM features are activated. |
| `llm_provider` | `str` | The configured provider id (`"null"` in demo mode, `"gemini"` when live). |

**Errors.** None. If the service is down the request fails at the transport layer.

**Example.**

```bash
curl -s http://127.0.0.1:8000/healthz | jq
```

```json
{ "status": "ok", "llm_enabled": false, "llm_provider": "null" }
```

## 3. Assets (`/assets`)

Router: [`backend/api/routes/data.py`](../backend/api/routes/data.py).

### `GET /assets`

[`backend/api/routes/data.py:19`](../backend/api/routes/data.py).

**Purpose.** List every active asset in the seeded universe.

**Request.** No body, no query parameters.

**Response — `200 OK`** — `list[AssetOut]`:

| Field | Type | Description |
|---|---|---|
| `id` | `int` | Internal asset id; used as FK from `backtest_runs`. |
| `symbol` | `str` | The trading symbol (e.g. `"SPY"`, `"BTC-USD"`, `"EURUSD"`). |
| `asset_class` | `str` | One of `equity`, `etf`, `crypto`, `fx`. |
| `name` | `str` | Human-readable name (e.g. `"SPDR S&P 500 ETF Trust"`). |
| `exchange` | `str` | Listing venue (`"NASDAQ"`, `"NYSE"`, `"BINANCE"`, `"FX"`, …). |
| `currency` | `str` | Quote currency (usually `"USD"`). |
| `is_active` | `bool` | False if the asset has been retired from the universe. |

**Errors.** None.

**Example.**

```bash
curl -s http://127.0.0.1:8000/assets | jq '.[:3]'
```

```json
[
  { "id": 1, "symbol": "AAPL", "asset_class": "equity", "name": "Apple Inc.",
    "exchange": "NASDAQ", "currency": "USD", "is_active": true },
  { "id": 5, "symbol": "SPY", "asset_class": "etf", "name": "SPDR S&P 500 ETF Trust",
    "exchange": "NYSE", "currency": "USD", "is_active": true },
  { "id": 22, "symbol": "BTC-USD", "asset_class": "crypto", "name": "Bitcoin / US Dollar",
    "exchange": "BINANCE", "currency": "USD", "is_active": true }
]
```

### `POST /assets/{symbol}/refresh`

[`backend/api/routes/data.py:25`](../backend/api/routes/data.py).

**Purpose.** Trigger a synchronous data fetch + clean + upsert for one symbol. The Data Agent fetches incrementally from the most recent stored bar.

**Path parameters.**

| Name | Type | Description |
|---|---|---|
| `symbol` | `str` | Trading symbol exactly as it appears in `GET /assets`. |

**Query parameters.**

| Name | Type | Default | Description |
|---|---|---|---|
| `timeframe` | `str` | `"1d"` | Either `"1d"` (daily) or `"1h"` (hourly). |

**Request body.** None.

**Response — `200 OK`** (`RefreshResponse`):

| Field | Type | Description |
|---|---|---|
| `symbol` | `str` | Echoes the path parameter. |
| `rows_written` | `int` | New or updated `OHLCVBar` rows. Zero means "already up-to-date". |
| `last_ts` | `datetime \| null` | Timestamp of the most recent bar after the refresh. |

**Errors.**

| Status | When |
|---|---|
| `400 Bad Request` | `FetcherError` raised by the underlying fetcher (e.g. yfinance's 730-day hourly cap if the start is older). |
| `404 Not Found` | The symbol is not in the seeded universe. |
| `500 Internal Server Error` | Other unexpected error. |

**Example.**

```bash
curl -s -X POST 'http://127.0.0.1:8000/assets/SPY/refresh?timeframe=1d' | jq
```

```json
{ "symbol": "SPY", "rows_written": 7, "last_ts": "2026-05-23T00:00:00" }
```

**Example.**

```json
  "description": "Fast-vs-slow simple-moving-average crossover with optional shorting.",
  "category": "trend",
  "params_schema": {
    "type": "object",
    "properties": {
      "fast_window": { "type": "integer", "minimum": 2, "maximum": 200, "default": 20 },
      "slow_window": { "type": "integer", "minimum": 5, "maximum": 500, "default": 50 },
      "allow_short": { "type": "boolean", "default": false }
    },
    "required": []
  }
}
```

## 5. Backtests (`/backtests`)

Router: [`backend/api/routes/backtest.py`](../backend/api/routes/backtest.py). This is the largest and most important router.

### 5.1 `POST /backtests`

[`backend/api/routes/backtest.py:60`](../backend/api/routes/backtest.py).

**Purpose.** Submit a backtest run. Executes **synchronously** in v1 — the request blocks until `BacktestAgent.run(...)` completes (typically sub-second on daily bars, a few seconds on hourly).

**Request body** — `BacktestRequest`:

| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `asset_symbol` | `str` | yes | — | Must match a row in `GET /assets`. |
| `strategy_slug` | `str` | yes | — | Must match a slug from `GET /strategies`. |
| `start_date` | `datetime` (ISO-8601 UTC, tz-naive) | yes | — | Inclusive lower bound. |
| `end_date` | `datetime` | yes | — | Inclusive upper bound. |
| `params` | `dict` | no | `{}` | Strategy parameters. Validated against the strategy's `params_schema`. |
| `initial_cash` | `float` (> 0) | no | `10000.0` | Starting capital in quote currency. |
| `commission_bps` | `float` (≥ 0) | no | `5.0` | Per-leg commission in basis points. |
| `slippage_bps` | `float` (≥ 0) | no | `2.0` | Per-leg slippage in basis points. |
| `risk_fraction` | `float` (0–1] | no | `1.0` | Fraction of equity to risk per position. |
| `sizing_mode` | `str` | no | `"fixed_fraction"` | Currently `"fixed_fraction"` only; vol-targeting is wired but unexposed. |
| `max_dd_pct` | `float` ([0, 1]) \| `null` | no | `null` | Optional circuit-breaker: halt the run if equity draws down more than this fraction. |
| `timeframe` | `str` (enum `Timeframe`) | no | `"1d"` | `"1d"` or `"1h"`. |

**Request headers.**

| Header | Required | Description |
|---|---|---|
| `X-Client-Id` | no | Anonymous per-browser UUID. Persisted as `BacktestRun.client_id` so that `GET /backtests` can scope history to the originating browser. The frontend generates and forwards this automatically; omit only from server-to-server calls where per-browser scoping is not needed. |

**Response — `201 Created`** (`BacktestSummary`):

| Field | Type | Description |
|---|---|---|
| `id` | `int` | The `run_id`. Use this for every subsequent `/backtests/{run_id}/…` call. |
| `strategy_id` | `int` | FK into `strategies`. |
| `strategy_name` | `str` | Joined name for convenience. |
| `asset_id` | `int` | FK into `assets`. |
| `asset_symbol` | `str` | Joined symbol for convenience. |
| `timeframe` | `str` | Echoes the request. |
| `start_date` / `end_date` | `datetime` | Echoes the request. |
| `status` | `str` | `"completed"` on success; `"failed"` on engine error (with `error_message` populated). |
| `error_message` | `str \| null` | Reason for failure, if any. |
| `created_at` / `completed_at` | `datetime` | Server-side timestamps. |

**Errors.**

| Status | When |
|---|---|
| `400 Bad Request` | Invalid `sizing_mode`; no bars in DB for the asset/timeframe in the requested window. |
| `404 Not Found` | Asset symbol does not exist. |

**Example.**

```bash
curl -s -X POST http://127.0.0.1:8000/backtests \
  -H 'Content-Type: application/json' \
  -d '{
    "asset_symbol": "SPY",
    "strategy_slug": "sma-crossover",
    "start_date": "2020-01-01T00:00:00",
    "end_date":   "2024-12-31T00:00:00",
    "params":     {"fast_window": 20, "slow_window": 50, "allow_short": false},
    "timeframe":  "1d"
  }' | jq '{id, status, strategy_name, asset_symbol}'
```

```json
{ "id": 17, "status": "completed", "strategy_name": "SMA Crossover", "asset_symbol": "SPY" }
```

### 5.13 `POST /backtests/{run_id}/report.pdf`

[`backend/api/routes/backtest.py:453`](../backend/api/routes/backtest.py).

**Purpose.** Render a client-assembled HTML report to a print-quality A4 PDF via headless Chromium. The client builds the full self-contained HTML (Plotly and fonts inlined) using `exportReportHtml` in `"pdf"` mode, then POSTs it; the server loads it in Playwright, waits for all figures to finish drawing (`window.__REPORT_READY__ === true`), activates `@media print`, and streams back `page.pdf()`. The PDF is pixel-identical to the interactive report.

**Request body** — `ReportPdfRequest`:

| Field | Type | Description |
|---|---|---|
| `html` | `str` | Fully self-contained HTML report document (Plotly and IBM Plex fonts inlined). |

**Response — `200 OK`** — `application/pdf` binary download with a `Content-Disposition: attachment` header.

**Errors.**

| Status | When |
|---|---|
| `404 Not Found` | Run does not exist. |
| `500 Internal Server Error` | Chromium render failed (timeout, crash, or JS error). |
| `503 Service Unavailable` | `playwright` package or its Chromium browser not installed. Run `pip install -r requirements.txt` then `playwright install --with-deps chromium`. |

**Example.**

```bash
curl -s -X POST http://127.0.0.1:8000/backtests/17/report.pdf \
  -H "Content-Type: application/json" \
  -d '{"html": "<html>...</html>"}' \
  -o report.pdf
```

## 6. Explain (`/explain`)

Router: [`backend/api/routes/explain.py`](../backend/api/routes/explain.py).

### `POST /explain`

[`backend/api/routes/explain.py:20`](../backend/api/routes/explain.py).

**Purpose.** Natural-language Q&A about runs, metrics, and strategies. Dispatched to the Explanation Agent's five operations.

**Request body** — `ExplainRequest`:

| Field | Type | Required for op | Description |
|---|---|---|---|
| `op` | `str` (enum) | always | One of `explain_metric`, `explain_strategy`, `compare_runs`, `answer_question`. (`report_run` is exposed via the `/backtests/{run_id}/report` endpoints instead.) |
| `run_id` | `int \| null` | `explain_metric`, `compare_runs`, `answer_question` | The primary run. |
| `other_run_id` | `int \| null` | `compare_runs` | The run to compare against. |
| `metric_name` | `str \| null` | `explain_metric` | The metric key to interpret (e.g. `"sharpe"`). |
| `strategy_slug` | `str \| null` | `explain_strategy` | The strategy whose behaviour should be explained. |
| `user_question` | `str \| null` | `answer_question` | The free-form question. |

**Response — `200 OK`** — `ExplainResponse`:

| Field | Type | Description |
|---|---|---|
| `op` | `str` | Echoes the request. |
| `text` | `str` | The LLM (or demo) response, markdown. |
| `model` | `str` | Provider model id. |
| `prompt_tokens` / `completion_tokens` | `int` | Token accounting. |
| `demo_mode` | `bool` | True iff `NullProvider`. |

**Errors.**

| Status | When |
|---|---|
| `400 Bad Request` | Missing or mismatched field for the requested `op`. |
| `429`, `502`, `503` | Same as `/backtests/{run_id}/report` POST. |

**Example.**

```bash
curl -s -X POST http://127.0.0.1:8000/explain \
  -H 'Content-Type: application/json' \
  -d '{ "op": "explain_metric", "run_id": 17, "metric_name": "sharpe" }' | jq '.text'
```

## 8. Error catalogue

| Status | Meaning in this app |
|---|---|
| `200 OK` | Standard success for `GET` endpoints. |
| `201 Created` | Used by `POST /backtests` and `POST /backtests/{run_id}/report`. `POST /backtests/{run_id}/report.pdf` returns `200`. |
| `400 Bad Request` | Pydantic validation error, domain constraint (e.g. invalid `sizing_mode`, no bars in DB, fetcher cap exceeded), or `report_run` on a not-completed run. |
| `404 Not Found` | Asset / strategy / run / benchmark not present. |
| `422 Unprocessable Entity` | FastAPI's body-validation default when a request payload doesn't match the Pydantic schema (e.g. missing required field, wrong type). |
| `429 Too Many Requests` | LLM provider rate-limited. |
| `500 Internal Server Error` | Unexpected unhandled error in a route handler. Check `uvicorn` logs. |
| `502 Bad Gateway` | LLM provider returned an unrecoverable error. |
| `503 Service Unavailable` | LLM provider reported transient overload. |
